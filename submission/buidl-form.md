Keycard

## Short description

```
Subscription access passes settled in native USDC on Arc. A merchant publishes a plan, a subscriber pays in a single transaction with no token approval, and any service gates access with one eth_call. The subscription is chain state, not a row in a database that a webhook has to keep in sync.
```
